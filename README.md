# M0615-DAW2 — Portfolio de proyectos

Repositorio personal con trabajos y prácticas del ciclo **DAW** (Desarrollo de Aplicaciones Web), principalmente del módulo **M0615** (Diseño de interfaces web).

El punto de entrada visual es [`index.html`](index.html), donde hay enlaces a los proyectos más representativos del módulo de diseño (y un enlace al portfolio del módulo **M0612** desplegado en Vercel).

---

## Aviso importante

**La mayoría de estos proyectos no son código de producción ni trabajo profesional.** Son ejercicios, prácticas de maquetación, clones de referencia, informes de usabilidad y prototipos hechos **en clase** para aprender HTML semántico, CSS, Bootstrap, Tailwind, responsive design, accesibilidad y criterios UX/UI.

Es habitual encontrar:

- Código experimental, duplicado o sin terminar
- Carpetas de prueba (`pruevasAnimaciones`, `pruebaSHADCN`, etc.)
- Proyectos en evolución con estilos o estructuras distintas según la sesión
- Informes y notas en subcarpetas (`fitness-boostrap/informes/`, `Sesiones/`)
- READMEs solo en subcarpetas concretas (p. ej. plantillas Vite), no en todo el repo

Si buscas referencias de calidad profesional, este repositorio **no** es el lugar adecuado. Si te interesa ver la evolución de prácticas de diseño web de un alumno de DAW, sí puede servir.
